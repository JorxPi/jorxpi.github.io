# Jordi Pi Moreno portfolio

Static HTML, CSS and JavaScript prepared for GitHub Pages. No build step or package installation is required.

## Preview

Run `python -m http.server 8080` from this directory and open http://localhost:8080.

## Publish on GitHub Pages

1. Create the public repository `jorxpi.github.io` under the JorxPi account.
2. Put the contents of this folder at the repository root. Keep `.nojekyll`.
3. In Settings → Pages, choose Deploy from a branch, `main`, and `/ (root)`.
4. GitHub will provide the published URL at https://jorxpi.github.io/.

Official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Content and updates

- `index.html`: introduction, selected projects, background and contact.
- Project HTML files: separate contribution breakdowns.
- `assets/style.css`: responsive design.
- `assets/site.js`: image enlargement and keyboard behavior.
- `assets/images`: supplied project screenshots and diagrams.
- `assets/documents/Jordi_Pi_Moreno_CV.pdf`: current CV with Def-A-Mole.

Sudden Death and Def-A-Mole link to their public source repositories. Their pages combine user-confirmed contributions with inspected code. Their covers use official YouTube video thumbnails, and their project pages embed the owner-supplied trailer/playthrough. BoundByDeath currently uses its main-menu background artwork while its trailer is in production. Earlier-project demo links were recovered from the owner’s old portfolio PDF. Sudden Death has no downloadable release, so no build-download button is shown.

The individual academic report is deliberately not bundled: it includes internal team material and hours that are not needed in a public portfolio.

Game screenshots and assets retain their original teams’ ownership. This is a personal portfolio; the contributions describe Jordi’s work within team projects. No third-party site source, artwork or template was copied.
