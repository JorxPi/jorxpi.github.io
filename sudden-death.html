THE PROJECT

Build the foundation.
Then build the game.

I developed a custom C++ engine using an Entity-Component-System architecture and OpenGL, alongside a strategy game that demonstrates it.

The thesis explored reusable game systems and reworked an intentionally unfair game concept into a strategic experience. Developing the engine and game together connected architectural decisions to the needs of a playable project.

01

Turn-based board gameplay

Cell selection and movement, summoned units, battle resolution and player scoring connect through the game manager.

02

Passive abilities

Separate passive behavior classes give units different effects while sharing a common interface.

03

Rendering and feedback

The OpenGL render system combines sprites and text by layer, supporting game screens, announcements and a visible game log.
